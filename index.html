📲 安装到手机真机测试指南

支持 PWA 免编译直接安装到手机桌面，或使用完整工程一键打包 Android APK

🔔 第一步：开启手机浏览器系统级通知与震动

授权后，当提醒时间到达或点击“测试推送”时，除了顶部横幅与提示音，还会同步调用手机系统级 Notification 与震动。

方式一：PWA 免编译直接安装成手机桌面独立 App（最快 · 30秒搞定）

本页面已内置完整的 PWA Manifest 与独立全屏配置，离线也可持久化保存数据：

  • Android (Chrome / Edge)：在手机浏览器打开本文件或部署链接，点击右上角菜单 “添加到主屏幕” / “安装应用”，即可像原生 App 一样从桌面全屏独立启动。
  • iPhone (Safari)：用 Safari 打开后点击底部 “分享”图标 -> “添加到主屏幕”，即可生成独立桌面图标并全屏运行。

方式二：使用随附的 Quasar + Capacitor 工程包生成原生 Android APK

聊天窗口中已同时提供完整工程压缩包 gf-companion-app-project.zip，支持两种打包方式：

  • 免配环境云端自动打包（推荐）：工程内置了 .github/workflows/build-android-apk.yml，将解压后的代码上传到你的 GitHub 仓库，GitHub Actions 会在 3 分钟内自动编译好 app-debug.apk 供你下载安装到手机。
  • 本地一键脚本打包：解压后在电脑终端运行 ./build-apk.sh（Mac/Linux）或双击 build-apk.bat（Windows），自动完成依赖安装与 APK 构建。
